Rock Paper Scissors

A console-based Rock Paper Scissors game built with JavaScript.

How to play
1. Open `index.html` in your browser.
2. Open the developer console (F12, then the Console tab).
3. In prompt, enter your choice (rock, paper, or scissor).
4. Play 5 rounds against the computer. The winner is announced at the end.

Features
- Random computer choice
- Case-insensitive input
- Score tracking for 5 rounds
